# Push policy

Commit locally as normal, but never `git push` on your own initiative —
not even for changes that seem obviously safe, small, or already
reviewed in this conversation. Push only after Simon gives an explicit
go-ahead for that push, in this chat, in the current turn. Approval to
push earlier in the conversation does not carry over to later commits;
ask again (or wait to be asked) each time. This rule applies to every
task from here on, whether or not the task description repeats it.
