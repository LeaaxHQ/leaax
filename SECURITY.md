# Security Policy

## Reporting a Vulnerability

If you've found a security vulnerability in Leaax, please report it to **security@leaax.com** rather than opening a public GitHub issue.

Please include:
- A description of the vulnerability and its potential impact
- Steps to reproduce it
- Any relevant logs, screenshots, or proof-of-concept code

We aim to acknowledge reports within a few days. As a small, actively maintained project, we can't guarantee a bug bounty, but we take reports seriously and will credit responsible disclosure if desired.

## Scope

This applies to the Leaax web application (leaax.com) and this repository. It does not cover third-party services we integrate with (Brave Search API, XposedOrNot) — please report issues with those directly to their respective maintainers.
